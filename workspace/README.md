# Sample workspace

- `problems/` has small coding problems. Each file has the statement, an empty
  function and a few checks. Write the body (the grey text is Ripple's
  suggestion, Tab accepts it), then press Run.
- `site/index.html` is a small web page. Open it to see the live preview.
- `hello.py` and `scripts/fizz.js` run with the Run button.
- `kernels/` holds GPU kernels. Switch to Kernel mode to see the PTX and the
  kernel report.

Start the server with `--workspace <folder>` to open your own project.
